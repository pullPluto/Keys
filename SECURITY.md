# Security policy

Please do not file public issues for suspected vulnerabilities. Report them through PullPluto's private security reporting channel once one is designated; the reporting address and response targets are **TBD by the security owner**.

Until then, restrict reports to repository administrators and include reproduction steps, affected commit, impact, and any suggested mitigation. Do not include customer data, credentials, or exploit payloads beyond what is necessary to reproduce safely.

See `docs/security/` for implementation requirements and limitations. This document does not make a response-time commitment.
